1. 프로세스와 CPU 하드웨어의 관계

운영체제가 관리하는 메모리와 CPU 코어가 독점하는 초고속 레지스터 세트

🏢 가상 메모리 공간 (RAM) 128 TB (공유)

프로세스가 실행되면 운영체제(OS)로부터 독립된 거대한 가상 주소 공간을 부여받습니다.

Code (Text)
기계어 바이너리 (r-x)
Data / BSS
전역 변수 (rw-)
Heap
동적 할당 (malloc / new)
Stack
함수 호출 & 지역 변수 (8MB)
⚡ CPU 코어 내부 레지스터 (코어 독점) 0.2 나노초

스레드가 CPU 코어에 안착(컨텍스트 스위칭)할 때 오직 그 스레드만 독점적으로 사용하는 물리 메모지입니다.

코어 활성 스레드 레지스터 뱅크
PC: 0x0000 | SP: 0x0000 | X0~X30 대기
  • 초고속 연산: RAM보다 수백 배 빠른 0~1사이클 연산 속도
  • 크기: 64비트 레지스터 약 32개 = 총 256바이트 남짓
  • 주소 없음: 포인터로 주소(`&`)를 딸 수 없으며, 이름으로 직접 지목
  • 컨텍스트 스위칭: 스레드가 교체될 때 이 값들이 메모리에 백업/복원됨
📦 레지스터 백업
💡 [컨텍스트 스위칭 시뮬레이션] 버튼을 눌러 RAM의 스레드 상태가 CPU 코어로 로드되는 과정을 확인하세요.

2. 핵심 특수 레지스터 4총사

프로그램의 실행 흐름(흐름 제어, 스택, 함수 호출)을 전담하는 핵심 하드웨어 장치

PC 64-bit
Program Counter
"다음에 실행할 기계어의 메모리 주소"
CPU가 명령어를 한 줄 읽어올 때마다 자동으로 4바이트씩 전진합니다. 점프 명령어(`B`, `BL`)를 만나면 목적지 주소로 덮어써집니다.
SP 64-bit
Stack Pointer (X31)
"현재 스택 메모리의 최상단 유효 주소 번지"
변수를 만들 때 `sub sp, sp, #16`으로 주소를 깎아 공간을 파고, 함수가 끝나면 `add sp, sp, #16`으로 복원합니다. (16바이트 정렬 필수)
LR (X30) 64-bit
Link Register
"함수가 끝나고 나중에 돌아올 복귀 주소"
`bl _main`으로 함수를 부르면 다음 줄 주소가 여기에 백업되며, 함수 끝에서 `ret`을 실행하면 이 LR 값이 다시 PC로 복사되어 복귀합니다.
FP (X29) 64-bit
Frame Pointer
"현재 함수의 스택 프레임 기준 베이스 주소"
SP가 함수 안에서 수시로 오르내릴 때, 지역 변수들의 안정적인 기준점 역할을 하여 디버거가 함수 호출 스택(콜스택)을 추적할 수 있게 돕습니다.

3. 범용 레지스터 (X0 ~ X28)

계산, 함수 인자 전달, 임시 저장을 위한 31개의 64비트 일꾼 레지스터

X0 ~ X7 함수 인자 / 반환

함수 호출 규약 (ABI):

• X0: 함수의 리턴값(Return Value)이 담기는 전 세계 표준 자리!

• X0 ~ X7: 함수를 호출할 때 1번째~8번째 매개변수를 담아서 전달합니다.

X9 ~ X15 임시 (Scratch)

호출자 보존 (Caller-saved):

함수 안에서 사칙연산(`ADD`, `MUL`) 계산용으로 자유롭게 막 쓰고 버릴 수 있는 임시 메모지입니다.

다른 함수를 호출하면 값이 날아갈 수 있습니다.

X19 ~ X28 영구 보존

피호출자 보존 (Callee-saved):

중요한 변수를 담는 방입니다.

함수가 이 레지스터를 쓰고 싶다면, 반드시 원래 있던 값을 스택에 백업해 두고, 함수가 끝날 때 원래대로 복원해 줘야 합니다.

🔬 하드웨어 비트 슬라이서: 64비트(X0) vs 32비트(W0) 물리 구조
Bit 63 Bit 32 Bit 31 Bit 0
상위 32비트 [63:32] (Upper 4B)
0x00000001
하위 32비트 [31:0] (W0 슬라이스: 4B)
0xA0B1C2D3
⮜────────────── X0 전체 (64-bit, 8바이트 메모리 주소 / 포인터 / int64) ──────────────⮞
💡 X0 모드 (64-bit): 64비트 전체 레지스터로 포인터(메모리 주소)나 큰 정수(`long`, `int64_t`)를 담을 때 8바이트 전체를 연산합니다.

4. 특수 하드웨어 & 실수/시스템 레지스터

0값 전용 하드웨어 접지, IEEE 754 부동소수점, 페이지 테이블 주소

XZR / WZR Zero Register

"읽으면 항상 0, 쓰면 버려짐"

하드웨어 접지선(GND)처럼 물리적으로 0으로 묶여있는 마법의 레지스터입니다.

변수를 0으로 초기화하거나, 결과값을 버리고 플래그만 세팅할 때 씁니다.

D0 ~ D31 (V) IEEE 754 FPU

"실수(소수점) & 벡터 연산기"

정수 레지스터(X0)와 물리 회로가 아예 다른 부동소수점 전용 64비트 레지스터입니다.

아까 배운 `double 3.14`가 바로 이 D0 레지스터에 탑재되어 계산됩니다.

TTBR0_EL1 시스템 레지스터

"L0 페이지 테이블 주소 보관함"

우리가 앞서 배운 4단계 가상 메모리 장부의 뿌리(L0) 시작 주소가 들어있는 특수 레지스터입니다.

오직 OS 커널만 이 레지스터를 수정할 수 있습니다.
