2. CPU 명령어 사이클 스튜디오 (Fetch ➔ Decode ➔ Execute ➔ Writeback)

하나의 명령어가 메모리에서 나와 연산되어 레지스터에 저장되기까지의 전체 흐름입니다.

🎯 실행 중인 명령어 (Arm64 어셈블리)
add w0, w1, w2
• 기계어 코드: 0x0B020020
• 연산 목표: W0 = W1(15) + W2(27) = 42
1. FETCH (명령어 인출) 대기
PC(0x1000)가 L1 캐시에 주소를 보내 기계어를 IR로 가져옵니다. (동시에 PC는 0x1004로 전진!)
2. DECODE (해석 및 준비) 대기
디코더가 기계어를 분석(ADD 연산)하고 레지스터에서 인자값 W1(15), W2(27)를 꺼냅니다.
3. EXECUTE (산술 연산) 대기
ALU(가산기 회로)로 15와 27이 들어가 15 + 27 = 42 연산을 완료합니다.
4. WRITEBACK (결과 저장) 대기
ALU의 결과값 42를 최종 목적지인 W0 레지스터에 기록(Latch)하여 1개 사이클을 마칩니다.
