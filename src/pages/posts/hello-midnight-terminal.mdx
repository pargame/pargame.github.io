# 블로그 리뉴얼: Midnight Terminal과 GitHub Actions 모던 아키텍처

기존 `MyBlog` 저장소를 이어받아, 개인 엔지니어링 지식 허브이자 기술 블로그인 **pargame.github.io**를 공식 리뉴얼했습니다.

## 1. 리뉴얼의 핵심 목표

단순한 텍스트 나열을 넘어 다음 네 가지 핵심 가치를 실현하고자 했습니다:

1. **GitHub Actions 기반 모던 배포**: 브랜치 커밋 오염 없는 공식 아티팩트 직접 배포
2. **Midnight Terminal 디자인 시스템**: 딥 인디고 블랙과 시안/바이올렛 액센트의 개발자 감성
3. **트랙-토픽-포스트 확장형 아키텍처**: C++, 언리얼 엔진, 네트워크, 동시성, DB, CS 기초의 체계적 학습
4. **인터랙티브 위젯 연동**: WebGL/Canvas 시뮬레이션 및 Pyodide 웹 파이썬 REPL 실행 환경

## 2. GitHub Actions 공식 배포 워크플로우

GitHub Pages 공식 가이드라인을 준수하여 작성된 `.github/workflows/deploy.yml`의 핵심 구조입니다:

```yaml
# .github/workflows/deploy.yml
name: Deploy GitHub Pages

on:
  push:
    branches: ["main"]

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: "pages"
  cancel-in-progress: false

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 26
      - run: npm ci
      - run: npm run build
      - uses: actions/upload-pages-artifact@v3
        with:
          path: './dist'

  deploy:
    needs: build
    runs-on: ubuntu-latest
    steps:
      - uses: actions/deploy-pages@v4
```
